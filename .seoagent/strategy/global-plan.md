# Глобальный план SEO — vsevmeste.space

Цель: стабильный органический поток владельцев салонов / СТО / кафе на регистрацию.
Честно: «гарантии» в SEO нет. Ниже — план, при выполнении которого трафик **становится ожидаемым результатом**, а не случайностью. Без фаз 0–2 люди из поиска почти не придут, даже с идеальными текстами.

Горизонт: **90 дней** до первых регулярных кликов; **6 месяцев** до ощутимого канала.

---

## Исходная точка (факт)

- GSC: `sc-domain:vsevmeste.space` подключён; бренд/домен почти без истории impressions.
- Индексация слабая: деньги-URL (`/salon`, `/avtoservis`, сравнения) часто *Discovered/Crawled — not indexed*.
- Техника в целом ок (meta, canonical, schema, robots, sitemap), когда сайт отвечает.
- Контентные кластеры salon / autoservice / cafe / compare уже расширены в репо.
- Конкуренты в SERP: YCLIENTS, Dikidi, Glowfy, mivvo, информационные listicle.

Узкое место сейчас не «нет статей», а **индексация + доверие + охват запросов + внешние сигналы**.

---

## Фаза 0 — Фундамент (неделя 1) · без неё остальное бессмысленно

**Критерий готовности:** sitemap стабильно 200; в GSC и Яндекс.Вебмастере sitemap принят; ≥80% приоритетных URL имеют вердикт Inspection; аптайм без таймаутов на деплое.

1. Стабильность origin при деплое (sitemap через Django не должен пропадать на 10–30 мин).
2. Повторно отправить sitemap в Google Search Console и Яндекс.Вебмастер.
3. URL Inspection + «Запросить индексирование» для приоритета:
   - `/` `/salon` `/avtoservis` `/kafe` `/businesses`
   - `/blog` + топ-10 коммерческих постов (YCLIENTS, WhatsApp, запись в салоне, программа СТО, QR-меню)
4. Проверить Яндекс.Вебмастер: главная зеркало, регион РФ, sitemap, Турбо не обязателен.
5. `seoagent indexing --max 40` еженедельно, пока coverage money-pages < 70%.

**Метрика фазы:** `/salon` и `/avtoservis` = Indexed (не Discovered).

---

## Фаза 1 — Страницы, которые конвертируют спрос (недели 1–4)

**Критерий:** у каждого кластера есть проиндексированный pillar + 3–5 спиц с внутренними ссылками вверх.

| Кластер | Запросы (intent) | Pillar | Задача |
|---|---|---|---|
| Салон | онлайн-запись салон, запись вместо WhatsApp | `/salon` | Держать 1200+ слов ценности, FAQ, демо, CTA регистрация |
| СТО | программа для автосервиса, онлайн-запись СТО | `/avtoservis` | То же + приёмка/VIN как отличия |
| Кафе | QR-меню кафе | `/kafe` | То же + демо `/m/demo-cafe` |
| Сравнение | yclients альтернатива, dikidi | compare-посты | Честные таблицы, без клеветы; захват navigational |

Работы:

1. Добить supporting spokes: виджет на сайт, каталог услуг, миграция с CRM (уже в блоге — углубить до 800–1200 слов где тонко).
2. Главная: больше server-visible текста/якорей на `/salon` `/avtoservis` `/kafe` (не только после JS).
3. Города (`/city/*` уже частично в индексе): блок «онлайн-запись для бизнеса в {городе}» → ссылка на `/salon` + регистрация.
4. Единый шаблон FAQ + JSON-LD на всех money pages (часть уже есть).

**Метрика фазы:** GSC impressions > 0 по небрендовым запросам; CTR не важен на старте.

---

## Фаза 2 — Яндекс + Wordstat (параллельно с фазой 1)

В РФ без Яндекса план неполный.

1. Яндекс.Вебмастер: все ключевые URL в индексе / «не индексируется» разобрать по причинам.
2. Wordstat (скилл `yandex-wordstat`): топ-30 запросов по «онлайн запись», «программа салон», «программа автосервис», «qr меню» → привязать к URL в `keywords.md`.
3. Снять 10–15 частотных хвостов (как настроить…, вместо WhatsApp, vs YCLIENTS) — у нас уже есть URL; сверить title/H1 с формулировкой Wordstat.
4. Метрика / цели: цель «регистрация» + UTM из органики.

**Метрика фазы:** Яндекс показывает показы по ≥5 посадочным.

---

## Фаза 3 — Авторитет и внешние сигналы (недели 3–12)

Без ссылок и упоминаний новый SaaS на конкурентном «онлайн-запись» почти не пробивает YCLIENTS/Dikidi.

1. **Партнёрский / контентный PR (не покупка спама):**
   - 4–6 гостевых/экспертных материалов: «как уйти от WhatsApp-записи», «чек-лист СТО», «QR-меню без приложения» на отраслевых блогах / VC / Habr (где уместно продукту).
   - Каталоги ПО и подборки «альтернативы YCLIENTS» — честное размещение с фактами тарифа.
2. **Локальные сигналы:** карточки организаций клиентов на Яндекс Картах / 2ГИС со ссылкой на /w/… (продуктовый growth = SEO-эхо).
3. **Бренд:** запросы «вместе vsevmeste» / «vsevmeste запись» — через соцсети, RuStore (Android), демо.
4. Запрещено: PBN, массовый линкспам, накрутка ПФ.

**Метрика фазы:** ≥15 referring domains с тематических/нейтральных источников; бренд-impressions в GSC.

---

## Фаза 4 — Программатика и масштаб (месяцы 2–4)

Когда pillars в индексе и есть клики:

1. Усилить city-landing: уникальный текст + локальные кейсы/формулировки, не doorway.
2. Публичные страницы организаций `/o/…` уже в sitemap — качество карточек (фото, услуги, адрес) = long-tail «запись {название}».
3. Кластер маркетплейсы / Vsayte — только после того, как booking-кластер даёт регистрации (не распыляться).

**Метрика фазы:** рост уникальных посадочных с кликами; доля organic в регистрациях > 10%.

---

## Фаза 5 — AEO / AI-поиск (параллельно с 3–4)

1. Заполнить `.seoagent/okf/` и задеплоить `llms.txt` / `.well-known/okf/`.
2. Страницы-ответы: чёткие определения, FAQ, таблицы сравнения (уже начато).
3. Следить, что AI-ответы не врут про тариф/WhatsApp (только исходящие).

**Метрика фазы:** упоминания/цитаты в AI-ответах (ручной набор промптов раз в месяц).

## Операционный ритм (каждую неделю)

| День | Действие |
|---|---|
| Пн | `seoagent sync` → inbox; `seoagent indexing` snapshot |
| Ср | 1 статья refresh или 1 новая long-tail по Wordstat/GSC |
| Пт | 1 внешний outreach (каталог / гостевой пост / партнёр) |
| Раз в 2 нед | IndexLift на `/salon` + `/` ; сравнить score/warnings |
| Ежемесячно | Отчёт: indexed %, impressions, clicks, registrations from organic |

Каденс агента: открывать Cursor Agent и говорить «продолжи SEO / process inbox» (см. `schedule` в `project.md`).

## Приоритет URL на ближайшие 30 дней (строго)

1. Проиндексировать: `/salon` `/avtoservis` `/businesses` + YCLIENTS-пост + WhatsApp-пост + salon-setup  
2. Углубить: `vidzhet-online-zapisi-na-sajt`, `katalog-uslug-i-ceny`, `kak-perejti-s-drugoj-crm`  
3. City → salon internal links  
4. Яндекс.Вебмастер + Wordstat map  
5. 4 внешних размещения  
6. OKF / llms

## Что считать «люди начали приходить»

Не «позиция 1 по yclients». Рабочие пороги:

| Срок | Сигнал успеха |
|---|---|
| 2–4 недели | Money-pages Indexed; первые impressions |
| 6–8 недель | Стабильные клики по long-tail (как настроить…, вместо WhatsApp) |
| 3 месяца | Регистрации с organic (GSC + Метрика) каждую неделю |
| 6 месяцев | Organic — узнаваемый канал рядом с сарафаном/рекламой |

Если после фаз 0–2 (индекс + контент + Яндекс) за 8 недель **ноль** impressions на `/salon` — чинить не «ещё 50 статей», а доступность, noindex/canonical, качество/дубли и внешние сигналы.

---

## Зависимости вне SEO-команды

- Продукт: демо `/w/demo-salon` и `/m/demo-cafe` всегда живые.
- Саппорт/контент: 1 реальный мини-кейс в месяц (с разрешением) сильнее 10 абстрактных гайдов.
- Маркетинг: нельзя ждать только SEO — параллельно RuStore, карты, короткие демо-видео под те же запросы.
