# Черновик: Habr (outline) — уход от записи через WhatsApp к публичным слотам

**Статус:** outline для owner/reviewer (не публиковать без правок и скринов).  
**Целевые ссылки:** `/salon`, `/avtoservis`, `/blog/zapis-vmesto-whatsapp`, `/businesses`  
**Тон:** инженерный, без накрученных метрик; честно про границу «исходящие напоминания, не inbox».

## Рабочее название

Как салону или СТО перестать терять слоты в WhatsApp, не покупая тяжёлую CRM

## Лид (3–4 предложения)

- Боль: дубли слотов, «есть ли окно в пятницу?», админ как живой API.
- Тезис: публичная ссылка на свободные окна + календарь ≠ отказ от мессенджера навсегда.
- Disclaimer: Вместе — один из вариантов; автор дисклеймер про аффилиацию если публикует владелец продукта (лучше — нейтральный экспертный тон или колонка «опыт внедрения»).

## Структура

1. **Почему WhatsApp ломается на 30+ записях в неделю**  
   - Нет единого источника правды по слотам.  
   - Несколько мастеров / постов → несколько чатов.  
   - Нет привязки напоминания к конкретному слоту.

2. **Что нужно минимально (MVP записи)**  
   - Каталог услуг с длительностью.  
   - График / посты / мастера.  
   - Публичная ссылка + тест от лица клиента.  
   - Скрин: демо `/w/demo-salon` или стейдж.

3. **Параллельный запуск (без «выключили WhatsApp в пятницу»)**  
   - Закреп ссылки в шапке профиля + автоответ.  
   - Старые клиенты — личка; новые — слот.  
   - Ссылка на VC: https://vc.ru/id6086968/3275832-kak-uiti-ot-zapisi-cherez-whatsapp-chek-list-dlya-salona-i-sto

4. **СТО: отличия от салона**  
   - VIN, приёмка, статусы ремонта.  
   - Ссылка на `/avtoservis` и VC СТО-чеклист.

5. **Напоминания: исходящие каналы vs «чат с клиентом»**  
   - Telegram / SMS / Green-API — исходящие.  
   - Явно: входящий WhatsApp-inbox CRM не заменяется.  
   - Ссылки: `/blog/telegram-napominaniya-organizacii`, `/blog/sms-napominaniya-o-zapisi`.

6. **Когда тяжёлая CRM оправдана**  
   - Сеть, склад, касса, ЗП — не целевой кейс лёгкого кабинета.  
   - Сравнение без клеветы: таблица «салон 2–5 кресел / СТО 2–4 поста / сеть 20+».

7. **Чек-лист через 2 недели после запуска**  
   - % записей через ссылку vs личка (субъективно, без выдуманных %).  
   - Пустые слоты: график заполнен?  
   - Один официальный URL для всех мастеров.

8. **CTA (мягкий)**  
   - Бесплатный тариф без срока, Бизнес 990 ₽/мес, без комиссии с записи.  
   - `https://vsevmeste.space/salon` · `https://vsevmeste.space/avtoservis`

## Хабр-мета

- **Хабы:** Бизнес, Разработка (если акцент на интеграции), или «Мессенджеры» — уточнить editor.  
- **Карточка:** 1–2 скрина кабинета + публичная запись (без персональных данных).  
- **Комментарии:** заготовить ответы про WhatsApp inbox и тарифы (OKF/оферта).

## Не включать

- Выдуманные ROI %, «в 10 раз больше клиентов».  
- Утверждения про позиции в Google/Яндекс.
