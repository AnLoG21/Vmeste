Публичная страница организации

Виджет /w/… — про слот. Публичная страница — про доверие: кто вы, где находитесь, какие услуги, как связаться. С карты и шаринга клиент часто попадает сначала сюда, а уже потом в запись.

Страница vs виджет

  • Страница — витрина и контекст
  • /w/… — быстрый выбор слота
  • Виджет на сайт — iframe для своей вёрстки

Несколько точек

Филиалы на одной организации — клиент видит адреса; гайд по филиалам.

Частые ошибки

  • Красивое название, пустой прайс — уходят
  • Адрес «Москва» без улицы — карта бесполезна
  • Шарится только страница без /w/… — лишний шаг до слота
