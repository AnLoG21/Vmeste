# Вэфире agent (ноут → HDMI → ТВ)

Агент на ноутбуке, подключённом к Philips по HDMI. Телефон шлёт ссылку в Вместе → агент забирает задачу и открывает её на весь экран.

## 1. Настройки Windows (один раз)

1. HDMI в телевизор, источник HDMI на ТВ  
2. `Win + P` → **Только второй экран**  
3. Параметры → Система → Питание → при закрытии крышки → **Ничего не делать** (от сети)

## 2. Запуск агента

```bat
cd tools\vefire-agent
copy .env.example .env
notepad .env
python -m pip install -r requirements.txt
python agent.py
```

В `.env` укажи логин/пароль `a.loginov150` (или refresh-токен).

Окно браузера откроется в kiosk/fullscreen на ТВ.

## 3. С телефона

Кабинет → Сервисы → **Вэфире** → приложение или «Ссылка» → **На ТВ**.
