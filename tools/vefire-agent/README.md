# Вэфире TV Agent — ноут как приставка + пульт с телефона

Ноутбук по HDMI к телевизору показывает сайт (Кинопоиск и т.д.).  
Телефон открывает **зеркало экрана** и управляет: тап, скролл, поиск, перемотка клавишами.

## Крышка ноутбука закрыта

1. Подключи **HDMI** к Philips, на ТВ выбери HDMI  
2. `Win + P` → **Только второй экран**  
3. Параметры Windows → Система → Питание и батарея → **Крышка** / доп. параметры питания  
   → «При закрытии крышки» → **Ничего не делать** (для «От сети» обязательно)  
4. Ноут от зарядки, не клади на мягкое (нагрев)  
5. Запусти `run.bat`, закрой крышку — картинка остаётся на ТВ  

Если засыпает: `powercfg /change standby-timeout-ac 0`

## Установка на любом Windows-ноуте

1. Скопируй **всю** папку **Vefire-TV-Agent** (не один run.bat)  
2. Установи [Python 3.11+](https://www.python.org/downloads/) с галкой **Add python.exe to PATH**  
3. Нужен **Microsoft Edge** или Chrome  
4. Открой `.env` — должен быть пароль `VEFIRE_PASSWORD=...` (если пусто, окно само предложит заполнить)  
5. Запускай **`START.bat`** (он держит окно открытым). Или `run.bat`.  
6. Окно **нельзя закрывать**. Если пропало — чаще Edge ушёл в fullscreen: **Alt+Tab** → «Vefire TV Agent».  
7. Рядом появится `RUNNING.txt` / `agent-run.log` — если агент жив, там свежий лог.  
8. При падении `run.bat` сам перезапускает через 5 сек.  

Частые причины на втором ноуте: нет Python в PATH, пустой `.env`, нет интернета, Edge перекрыл консоль на весь экран.

## Как смотреть

1. Агент запущен на ноуте у ТВ  
2. Телефон: Вместе → Сервисы → **Вэфире** → приложение → **На ТВ**  
3. Там же кнопка **Пульт** — зеркало экрана ТВ внутри Вместе (отдельная ссылка не нужна)  
4. На пульте: жесты по картинке, поле поиска, ◀/▶

## Файлы

- `run.bat` — установка зависимостей и запуск  
- `agent.py` — cast + MJPEG-пульт  
- `cdp_browser.py` — управление Edge/Chrome  
- `remote.html` — UI пульта  
- `.env` — логин (не коммить пароль)
